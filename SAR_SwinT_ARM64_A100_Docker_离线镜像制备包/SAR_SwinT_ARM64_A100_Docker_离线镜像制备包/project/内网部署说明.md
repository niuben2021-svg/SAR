# 内网部署快速指南

该 ZIP **仅包含项目完整源代码与使用说明**，不包含数据集、PyTorch/CUDA离线安装包或 Swin-T 预训练权重。没有联网时，须在联网机器上按内网操作系统、Python/CUDA/PyTorch版本预先准备兼容的离线依赖与权重。

## 目录结构

实际数据目录应形如：

```
dataset/
  trainval/{Annotations,KeyPoints,METAXmls,PNGImages,SLCMats}/
  test/{Annotations,KeyPoints,METAXmls,PNGImages,SLCMats}/
```

也支持 `dataset/SL-TRAINVAL/trainval/` 与 `dataset/SL-TEST/test/` 这类外层包装目录。

## 步骤（在代码目录内）

```bash
# 1. 检查依赖：python、torch、torchvision、numpy、PIL。
python -c "import torch, torchvision, numpy, PIL; from torchvision.ops import nms; print('torch',torch.__version__,'torchvision',torchvision.__version__,'cuda',torch.cuda.is_available())"
# 2. 检查目标类别和大小
python analyze_labels.py --data-root /data/dataset
# 3. 官方 trainval 中分出验证集，官方 test 不参与训练
python prepare.py --data-root /data/dataset --out split.json
# 4. 前向测试
python smoke_test.py --data-root /data/dataset --device cuda --tile 128
# 5. 使用512像素原生裁切训练（非缩放）
python train.py --data-root /data/dataset --split split.json --swin-weights /weights/swin_t-704ceda3.pth --tile 512 --epochs 24 --batch-size 2 --workers 4 --out-dir runs/swin_p1
# 6. 在验证集选择适当的检查点，然后评测官方测试集
python evaluate.py --checkpoint runs/swin_p1/last.pth --data-root /data/dataset --split split.json --subset test --out metrics_p1.json
```

四卡训练示例：

```bash
OMP_NUM_THREADS=4 torchrun --standalone --nproc_per_node=4 train.py --data-root /data/dataset --split split.json --swin-weights /weights/swin_t-704ceda3.pth --tile 512 --epochs 24 --batch-size 2 --workers 4 --out-dir runs/swin_p1_4gpu
```

**重要**：`--tile 512` 是1024×1024原图的 **512×512原像素裁切**，不会将直升机目标按比例缩小。`--swin-weights` 需要 TorchVision Swin-T 格式的本地权重；当前项目采用P1高分辨率分支，其他代码详情见 `README.md`。

本代码为 SAR 幅度图检测基线，暂不包含复数子孔径增强模块。首次在完整数据上运行前，建议先核对标签类别、样本名称、场景划分和目标尺寸分布。
