# ADR-0003：新增 ARM64 SBSA / A100 / CUDA 12.6 交付

2026-10-28，用户要求按截图支持 ARM64 A100、驱动 560.35.03，原 x86_64 环境保留。

原镜像是 linux/amd64；不能把二进制重新标记成 arm64。新增原生 ARM runner 构建、独立镜像标签和 Release，所有下载入口汇总到 docker-images/。

官方 cu126 wheel 索引中没有截图建议的 Python 3.11 torch 2.8.0 / torchvision 0.23.0 ARM64 CUDA 组合。选择已有官方 wheel 的 torch 2.9.1+cu126 / torchvision 0.24.1，固定下载 SHA256，保留 Transformers 4.57.6 / ms-swift 4.6.0 / PEFT 0.20.0。沿用 Python slim + NVIDIA CUDA wheel 运行库，避免重复引入另一套 CUDA 基础镜像。

不采用 CPU ARM wheel 冒充 GPU 版本；不在本次任务从源码编译 PyTorch；不修改研究模型或数据接口。添加单 A100 保守配置及 ARM 架构检查启动器。原 run.sh 和双卡配置可复用。

CI 验证：原生 ARM64 架构、torch.version.cuda=12.6、torchvision CUDA 扩展、官方 Qwen/Swift 导入、pip check、既有离线 CPU 测试、Swift 配置字段。真实 A100 前向/反传、目标麒麟系统的 Toolkit 兼容性和显存使用仍需用户目标主机验证。
