# ADR-0001 实际内网硬件为两张 A100

日期：2026-10-22。决策来源：用户在本次会话明确报告麒麟V10、x86、NVIDIA驱动595.58.03、2张40GB A100；这些是目标参数，尚非远程命令实测。

原文档预算为4×A100 40GB。本次按实际两卡准备Linux amd64离线镜像和LoRA配置，不改变Qwen3-VL-8B底座、全局/原生tile、Object Head、物理证据或可信模块的研究路线。

双卡每卡micro batch1，梯度累积从4改为8，保留有效batch16。单卡先验收前向与少量步骤，再运行双卡。原四卡配置保留作原方案参考；不假定NVLink，也不把两卡80GB看成单卡80GB。

该硬件调整直接依据用户明确提供的信息实施，无须重复确认硬件数量。Docker/NVIDIA Container Toolkit和实际BF16/显存/吞吐仍需在内网验证，当前没有训练效果或性能结论。
